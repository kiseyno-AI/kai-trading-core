# GET /disclosures/dart/fundamentals

## Summary
Direct single-company DART fundamentals fetch.

## Example request
```http
GET /disclosures/dart/fundamentals?stock_code=005930&business_year=2024&report_code=11011&fs_div=CFS
```

## Example response
```json
{
  "stock_code": "005930",
  "business_year": 2024,
  "report_code": "11011",
  "fs_div": "CFS",
  "highlights": [],
  "rows": []
}
```
